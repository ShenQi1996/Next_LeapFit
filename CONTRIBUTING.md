# Contributing

This repository is maintained by Sam Qi (GitHub [@ShenQi1996](https://github.com/ShenQi1996)) for Secure Fit LLC.

## How to contribute

1. Branch from the latest `main`.
2. Name the branch in `snake_case`, like `name_yyyy_mm_dd_purpose`.
   Example: `sam_2026_10_23_repo_legal_files`.
3. Keep the change small and focused.
4. Before you open a pull request, run:

   ```bash
   npm ci && npm run build
   ```

5. Never commit secrets or `.env` files.

Security reports go to [SecureFit2024@gmail.com](mailto:SecureFit2024@gmail.com). See [SECURITY.md](SECURITY.md). Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
