# Security Policy

## Supported versions

The latest `main` branch is supported.

## Reporting a vulnerability

Report security vulnerabilities privately by email to [SecureFit2024@gmail.com](mailto:SecureFit2024@gmail.com).

Do not open a public GitHub issue for a security report. A public issue can expose the problem before it is fixed.

Please include:

- A short description of the issue
- Steps to reproduce it, if you can
- The impact you believe it has

We aim to reply within 7 days. We will confirm that we received the report, then follow up as we investigate and fix it.
